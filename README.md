# Jimothy Assets

Self-contained Blender 5.2 character projects for DRUNKEN KAIJU.

- `characters/Jimothy-Hero.blend`: textured character with fitted armature, HD and LOD meshes, and 18 animation clips.
- `characters/Jimothy-Procedural.blend`: earlier editable character with 18 animation clips.

Textures are packed into each project. Open a project in Blender and choose an action in the Dope Sheet's Action Editor. Idle is selected by default; NLA tracks are initially muted.

Facial and attack poses still need refinement.
